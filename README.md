🚢 Batalha Naval 2.0
Projeto desenvolvido em C# durante o treinamento da 5by5.


🎮 Sobre o projeto
O Batalha Naval 2.0 é uma versão em console do clássico jogo Batalha Naval, onde o jogador enfrenta o computador com o objetivo de afundar todas as embarcações adversárias. 


⚙️ Funcionalidades
Tabuleiro de jogo 10x10.
Posicionamento aleatório das embarcações.
Cinco navios de diferentes tamanhos.
Modo de jogo Jogador vs Computador.
Geração automática de ataques do computador.
Validação de coordenadas e posições já utilizadas.
Sistema de pontuação.
Identificação de acertos, erros e vencedor da partida.
